## About Third-Party Iframe Warnings

### Why Some CSP Warnings May Still Appear

**The CSP warnings you saw** (like `/v2.22/fingerprint`) come from **inside third-party iframes**:
- Paystack checkout popup
- Monicredit fingerprinting service
- Other payment fraud detection services

These are **browser-generated warnings** about the iframe's own CSP headers (which have invalid syntax with query parameters).

###  Why JavaScript Can't Suppress Them

1. **Cross-Origin Isolation:** Iframes run in separate browser contexts
2. **Browser-Level Warnings:** Generated by the browser, not JavaScript
3. **Security Model:** Parent page can't intercept iframe console messages

### Industry Standard Approach

**Every SaaS application with payment integrations** has this same situation:
- Stripe: Has similar warnings from 3DS authentication frames
- PayPal: Has warnings from their checkout iframe
- Square: Has warnings from their payment forms

**This is normal and expected** in production SaaS applications.

## Lazy-Loading Implementation

### Before (Global Loading):
```html
<!-- index.html -->
<script src="https://js.paystack.co/v1/inline.js"></script>
<!-- Loaded on EVERY page, even landing -->
```

### After (Lazy Loading):
```typescript
// src/lib/loadPaymentScripts.ts
import { ensurePaystackLoaded } from '@/lib/loadPaymentScripts';

// Only load when actually needed
await ensurePaystackLoaded();
const handler = PaystackPop.setup({ ... });
```

**Benefits:**
- ✅ Faster landing page (no unnecessary scripts)
- ✅ Clean console on non-payment pages
- ✅ Better user privacy (no tracking on landing)
- ✅ Reduced bandwidth usage
- ✅ Industry-standard approach

## Maintenance Guide

### Adding New Payment Gateways

1. **Add to lazy-loader:**
   ```typescript
   // src/lib/loadPaymentScripts.ts
   export async function loadStripeScript(): Promise<void> {
     await loadScript({
       src: 'https://js.stripe.com/v3/',
       id: 'stripe-js',
     });
   }
   ```

2. **Update CSP:**
   ```html
   <!-- index.html -->
   script-src ... https://js.stripe.com;
   frame-src ... https://checkout.stripe.com;
   ```

3. **Use lazy-loading:**
   ```typescript
   await loadStripeScript();
   // Now safe to use Stripe
   ```
